# SameImage

Windows 폴더의 완전 중복 이미지·영상과 **포맷·해상도·압축률이 다른 유사 파일 후보**를 찾는 로컬 데스크톱 앱입니다. 파일을 서버로 전송하지 않습니다.

## Windows 배포본

`release/SameImage-0.1.0-windows-x64.zip`을 전체 압축 해제한 뒤 `SameImage/SameImage.exe`를 실행합니다. Python 설치나 별도 패키지 설치 없이 사용하며 콘솔 창이 나타나지 않습니다. 실행 파일 옆의 `_internal` 폴더도 함께 배포해야 합니다. 현재 배포본은 설치 과정 없는 Windows x64용이며 코드 서명은 없습니다.

개발 환경에서 다시 빌드하려면:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe build_release.py
```

빌드는 `dist/SameImage` 실행 폴더를 만들고 실제 EXE의 자체 점검을 통과하면 ZIP과 `release/SHA256SUMS.txt`를 생성합니다. 자체 점검은 임시 미디어의 이미지·영상 유사 검색, HEIF 디코더, GUI 미리보기를 확인하며 실제 휴지통 이동은 하지 않습니다. 결과는 `release/package-self-test.json`에 저장됩니다. 외부 구성 요소의 라이선스 고지도 함께 포함됩니다.

## 실행

Python 3.11 이상(Tkinter 포함)을 설치한 뒤:

1. 처음 사용할 때 `setup.bat`으로 패키지를 설치합니다. 인터넷 연결이 필요합니다.
2. `SameImage.vbs`를 더블 클릭합니다. 명령 프롬프트 없이 앱만 실행됩니다. 현재 작업 환경에는 가상환경과 패키지가 설치되어 있습니다. 기존 `run.bat`도 앱 실행 후 콘솔이 닫히지만 시작 순간 잠깐 보일 수 있습니다.

```powershell
.\.venv\Scripts\python.exe app.py
```

패키지가 없더라도 시스템 Python으로 `python app.py`를 실행하고 **유사 파일 포함**을 해제하면 기존 완전 중복 검색은 사용할 수 있습니다.

## 사용 방법

1. 폴더와 이미지/영상 유형을 선택합니다. 하위 폴더까지 검색합니다.
2. **유사 파일 포함**을 켜고 민감도를 선택합니다. 기본값은 **보통**이며, **엄격**은 후보가 적고 **넓게**는 다른 파일도 포함될 가능성이 높습니다.
3. **중복 검색**을 누릅니다. 결과에 **완전 중복**과 **유사 후보**, 파일별 썸네일·용량·해상도·영상 길이가 표시됩니다. 영상 썸네일에는 재생 모양 표시가 붙습니다. 썸네일이나 파일명을 클릭하면 오른쪽에 크게 표시되며, 영상은 10·30·50·70·90% 버튼으로 장면을 바꿔 볼 수 있습니다. 앱 안에서는 정지 프레임을 표시하고 **원본 열기**로 기본 플레이어에서 재생합니다.
4. 결과의 파일이나 그룹을 선택하고 **나란히 비교**를 누릅니다. 오른쪽 파일은 가로 스크롤로 확인합니다. 영상은 10·30·50·70·90% 위치의 프레임을 왼쪽 위부터 행 순서로 보여줍니다.
5. 처음에는 모두 보관 상태입니다. 각 카드에서 없앨 파일의 **휴지통으로 보낼 파일**만 체크하고 **선택 확정 후 다음 그룹**을 누릅니다. 네 파일 중 두 개처럼 여러 파일을 남길 수 있으며, 최소 한 개는 보관해야 합니다. 모두 보관한 채 확정해서 넘어가도 됩니다. **이 파일만 보관**은 나머지를 한 번에 체크하는 빠른 선택이며, 이후 개별 체크를 조정하고 확정할 수 있습니다. **이전 그룹 / 다음 그룹**으로 돌아가 선택을 바꿀 수 있습니다. 미확정 변경은 비교창을 닫거나 그룹을 이동해도 현재 검색 세션에서 유지되지만 메인 화면의 정리 선택에는 확정한 뒤 반영됩니다. 새 검색이나 휴지통 이동으로 결과가 갱신되면 미확정 변경은 초기화됩니다. 해상도가 높은 파일이 먼저 표시되지만 원본 여부나 화질을 보장하지는 않습니다. **원본 열기**로 실제 파일도 확인할 수 있습니다.
6. 메인 화면에서 선택을 조정한 뒤 **결과 목록 위 오른쪽의 파란색 ‘선택 파일 정리 → 휴지통’** 버튼을 눌러 확인합니다. 각 그룹에서 최소 한 파일을 남기며, 선택 파일은 Windows 휴지통으로 이동합니다.

창 모드에서도 검색·정리 도구 영역은 유지됩니다. 보조 버튼은 너비에 따라 줄바꿈되고 결과 목록은 남은 공간에 맞춰 줄어듭니다. 미리보기가 세로로 잘리면 오른쪽 스크롤바로 이동하세요.

**완전 중복만 일괄 선택**은 유사 후보를 선택하지 않습니다. 유사 후보는 비교 화면에서 보관할 파일을 직접 정해야 합니다. **정리 열** 클릭이나 Space 키로 정리 선택을 조정할 수 있습니다. 썸네일·파일명 클릭은 미리보기만 바꾸며 정리 대상으로 선택하지 않습니다.

목록 썸네일은 화면에 보이는 파일부터 백그라운드에서 읽고 최근 128개까지 메모리에 보관합니다. 디코더가 지원하지 않거나 읽을 수 없는 파일은 **미리보기 없음**으로 표시하며, 검색 결과와 원본 열기는 그대로 사용할 수 있습니다.

휴지통을 비워야 실제 여유 공간이 늘어납니다. 휴지통 비우기는 사용자가 Windows에서 직접 진행합니다. 일부만 정리해도 나머지 검색 결과는 유지됩니다. 이동한 파일과 한 개만 남아 정리가 끝난 그룹만 결과에서 빠집니다. 도중에 실패하면 이동하지 못한 파일의 체크와 비교 확인 상태도 유지되어 다시 시도할 수 있습니다. 이미 이동한 파일을 다시 보관하려면 Windows 휴지통에서 복원하고 재검색하세요.

## 비교 방식

- **완전 중복:** SHA-256 해시를 비교합니다. 완전 중복 전용 모드에서는 파일 크기로 먼저 후보를 줄입니다.
- **유사 이미지:** EXIF 회전을 반영하고 크기를 정규화한 뒤, 저주파 형태를 나타내는 pHash와 4×4 색상 특징을 비교합니다. 종횡비도 확인합니다. 포맷 변환·축소·재압축 파일을 찾을 수 있으나 모든 변형을 검출하지는 않습니다.
- **유사 영상:** 길이가 비슷한 영상에서 같은 비율의 5개 지점을 추출하고, 모든 샘플의 형태와 색상이 기준을 통과해야 후보로 표시합니다. 해상도·코덱이 다른 파일도 비교합니다.
- 그룹 안의 모든 파일 쌍이 기준을 통과해야 합니다. A와 B, B와 C가 비슷하다는 이유만으로 서로 다른 A와 C를 같은 그룹에 넣지 않습니다. 그룹은 겹치지 않으며, 이 보수적인 구성 때문에 일부 유사 관계가 표시되지 않을 수 있습니다.
- 점수는 샘플의 특징 차이를 나타내는 지표이며 **일치 확률이나 정확도 백분율이 아닙니다.**

## 한계와 정리 동작

- 유사 파일은 내용이 완전히 같다는 보장이 없습니다. 특히 영상의 **음성, 자막 트랙, 샘플 사이 장면**은 비교하지 않습니다. 원본을 재생해 확인하세요.
- 자르기, 큰 회전, 워터마크, 색상 보정, 영상 앞뒤 편집, 화면 비율 변경 등은 놓칠 수 있습니다. 비슷한 구도나 단색 이미지가 후보로 잡힐 수도 있습니다.
- JPG, PNG, WebP, HEIC/HEIF, AVIF 등은 설치된 Pillow/HEIF 디코더 범위에서 지원합니다. RAW, 애니메이션·다중 페이지 이미지, 지원하지 않는 영상 코덱은 유사 비교에서 제외하고 오류 내역에 표시합니다. 읽을 수 있는 바이트가 같으면 완전 중복으로는 찾을 수 있습니다.
- 유사 검색은 모든 대상 파일의 해시와 시각적 특징을 읽으므로 완전 중복 전용 검색보다 오래 걸립니다. pHash를 여러 블록으로 나눈 인덱스로 후보를 줄인 뒤 기존 판정 기준을 적용합니다. 현재 임계값 안의 후보를 빠뜨리지 않도록 구성했으며 기존 순서대로 그룹을 만듭니다. 형태 기준을 통과한 후보만 색상을 계산하고, 한 번의 검색에서 바이트와 확장자가 같은 파일은 시각적 분석 결과를 재사용합니다. 비슷한 지문이 몰리면 여전히 최악에는 파일 수의 제곱에 비례합니다. 디코더 내부 작업 중에는 중단 반영이 늦어질 수 있습니다.
- 링크·정션·Windows 재분석 지점은 건너뛰고, 저장 공간을 공유하는 하드 링크는 한 번만 계산합니다. 일부 클라우드 파일도 제외될 수 있습니다.
- 정리 전 각 파일의 **검색 당시 SHA-256**을 다시 확인합니다. 유사 파일은 서로의 해시가 달라도 되지만, 검색 후 내용이 바뀌거나 보관 파일이 사라졌으면 정리를 중단합니다. 다른 앱에서 검색 대상 파일을 편집하거나 이동하지 마세요.
- 네트워크·일부 외장 드라이브나 휴지통 용량 초과 상황에서는 Windows가 영구 삭제 확인을 물을 수 있습니다. 휴지통 이동이 불가능하다는 안내가 나오면 취소하세요.
- 표시 용량은 논리적 파일 크기입니다. 파일 시스템 압축 등으로 실제 확보 용량과 다를 수 있습니다.

## 검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

임시 이미지·영상을 생성해 해상도/포맷/압축 변경, EXIF 회전, 다른 이미지 제외, 길이·코덱이 다른 영상, 유사 관계의 연쇄 병합 방지, 보관 파일 변경 차단을 확인합니다. GUI 테스트는 나란히 보기와 보관 선택, 정리 시 파일별 해시 검증을 확인합니다. 휴지통 함수는 테스트에서 대체하므로 실제 휴지통은 조작하지 않습니다.
