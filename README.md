# SameImageSearch

**이미지·영상의 중복과 유사 파일을 찾아, 직접 비교하고 필요한 파일을 남기는 Windows 데스크톱 앱입니다.** 앱 화면과 실행 파일의 이름은 **SameImage**입니다.

파일을 서버로 전송하지 않고 컴퓨터 안에서 분석합니다. 완전히 같은 파일뿐 아니라 포맷·해상도·압축률이 달라진 유사 파일도 후보로 표시합니다.

## 주요 기능

- **완전 중복 검색:** SHA-256 해시로 파일 내용을 비교합니다.
- **유사 이미지 검색:** 형태·색상·종횡비를 비교하며 EXIF 회전을 반영합니다.
- **유사 영상 검색:** 길이가 비슷한 영상의 5개 지점에서 장면을 비교합니다.
- **썸네일과 미리보기:** 결과 목록에서 내용을 확인하고, 영상을 구간별 정지 프레임으로 볼 수 있습니다.
- **나란히 비교:** 파일별로 보관·정리를 선택합니다. 한 그룹에서 여러 파일을 남길 수 있습니다.
- **선택 변경:** 이전 그룹으로 돌아가 체크를 수정하고 다시 확정할 수 있습니다.
- **부분 정리:** 일부만 휴지통으로 보내도 나머지 검색 결과는 유지됩니다.
- **창 모드 지원:** 도구 버튼은 줄바꿈되고 목록·미리보기는 스크롤할 수 있습니다.

## 시작하기

### 소스 코드로 실행

Windows 64비트와 **Python 3.11(Tkinter 포함)**을 기준으로 개발·검증했습니다. 패키지 설치에는 인터넷 연결이 필요합니다.

```powershell
git clone https://github.com/Jangwanko/SameImageSearch.git
cd SameImageSearch
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

또는 저장소 폴더에서 `setup.bat`으로 설치한 뒤 `SameImage.vbs`를 더블 클릭하면 콘솔 창 없이 실행됩니다. `run.bat`도 사용할 수 있지만 시작 순간 콘솔이 잠깐 보일 수 있습니다.

패키지를 설치하지 않은 경우에도 `python app.py`로 실행한 뒤 **유사 파일 포함**을 해제하면 완전 중복 검색은 가능합니다. 썸네일·나란히 비교·유사 검색에는 패키지 설치가 필요합니다.

### ZIP 배포본으로 실행

이 저장소에는 **소스와 빌드 설정**이 들어 있습니다. `dist/`, `release/`, 배포 ZIP은 Git에 포함되지 않으며, 저장소의 **Code → Download ZIP은 실행 파일 배포본이 아닙니다.** 실행용 ZIP을 전달받거나 아래 빌드 방법으로 생성하세요.

1. `SameImage-0.1.0-windows-x64.zip`을 **전체 압축 해제**합니다.
2. `SameImage` 폴더 안의 **`SameImage.exe`**를 실행합니다.
3. 옆에 있는 **`_internal` 폴더를 삭제하거나 분리하지 마세요.**

배포본은 Python 설치가 필요 없는 Windows x64용 포터블 앱입니다. 별도 설치 마법사와 코드 서명은 아직 없습니다.

## 검색하고 정리하기

### 1. 폴더 검색

**폴더 선택**으로 검색할 폴더를 지정하고 이미지·영상 유형을 고른 뒤 **중복 검색**을 누릅니다. 선택한 폴더의 하위 폴더도 함께 비교합니다. 서로 떨어진 여러 폴더를 동시에 지정하는 기능은 아직 없습니다.

**유사 파일 포함**을 켜면 다음 민감도를 선택할 수 있습니다.

| 조건 | 동작 |
| --- | --- |
| 엄격 | 작은 특징 차이만 허용합니다. |
| 보통 | 기본 설정입니다. |
| 넓게 | 더 큰 차이를 허용하므로 서로 다른 파일도 후보에 포함될 수 있습니다. |

결과에는 완전 중복·유사 후보 구분, 썸네일, 용량 등이 표시됩니다. 해상도·영상 길이는 분석 정보를 얻은 경우 표시합니다. 썸네일이나 파일명을 클릭하면 오른쪽에 크게 보이며, 이 클릭만으로 정리 대상에 체크되지는 않습니다.

영상은 **10·30·50·70·90%** 버튼으로 정지 프레임을 바꿔 볼 수 있습니다. 실제 재생은 **원본 열기**로 기본 플레이어에서 진행합니다.

### 2. 나란히 비교하고 선택

1. 결과에서 파일이나 그룹을 선택하고 **나란히 비교**를 누릅니다.
2. 처음 확인하는 그룹은 기본적으로 모두 보관합니다. 없앨 파일의 **휴지통으로 보낼 파일**만 체크하세요.
3. **선택 확정 후 다음 그룹**을 누르면 메인 화면에 체크가 반영되고 다음 그룹이 열립니다.

네 파일 중 두 파일처럼 **여러 개를 보관**할 수 있고, 모두 보관한 채 넘어가도 됩니다. 최소 한 파일은 반드시 남겨야 합니다. **이 파일만 보관**은 나머지를 한 번에 체크하는 빠른 선택이며, 이 경우에도 확정 버튼을 눌러야 반영됩니다.

**유사 후보는 비교창에서 선택을 확정해야 메인 화면에서 정리 체크를 조정할 수 있습니다.** 완전 중복은 메인 화면의 **정리 열** 또는 Space 키로 바로 선택할 수 있습니다. **완전 중복만 일괄 선택**은 유사 후보를 제외하고 완전 중복 파일만 선택합니다.

### 3. 이전 선택을 바꾸거나 취소

**이전 그룹**으로 돌아가 체크를 바꾸고 **선택 확정 후 다음 그룹**을 다시 누르면 기존 선택을 교체합니다. 서로 다른 사진이었다면 체크를 모두 해제하고 확정하면 됩니다.

비교창을 닫거나 그룹을 이동해도 미확정 변경은 현재 검색 세션에서 이어집니다. 다만 **확정하지 않은 변경은 메인 화면의 정리 대상에 반영되지 않습니다.** 새 검색이나 휴지통 이동으로 결과가 갱신되면 미확정 변경은 초기화됩니다. 앱을 종료한 뒤 검색 결과를 복원하는 기능은 없습니다.

### 4. 휴지통으로 이동

메인 화면 **결과 목록 위 오른쪽의 파란색 `선택 파일 정리 → 휴지통` 버튼**을 누르고 확인합니다.

- 일부만 정리해도 나머지 검색 결과는 유지됩니다. 이동한 파일과 한 개만 남은 그룹만 결과에서 빠집니다.
- 이동에 실패하면 남은 파일의 체크와 비교 확인 상태를 유지합니다.
- 이미 이동한 파일을 다시 보관하려면 Windows 휴지통에서 복원하고 재검색하세요.
- **실제 여유 공간은 휴지통을 비운 뒤 늘어납니다.** 앱은 휴지통을 자동으로 비우지 않습니다.

## 비교 방식과 한계

완전 중복 전용 검색은 파일 크기로 후보를 줄인 뒤 SHA-256 해시를 비교합니다. 유사 검색은 이미지의 pHash·색상 특징을, 영상의 길이와 5개 샘플 프레임을 비교합니다. 그룹 안의 모든 파일 쌍이 기준을 통과해야 하며, 점수는 **일치 확률이나 정확도 백분율이 아닙니다.** 해상도가 높은 파일을 먼저 표시하지만 원본 여부나 화질을 보장하지는 않습니다.

- **부분 영상 검색은 지원하지 않습니다.** 10초 클립이 2시간 영상의 일부인지 찾는 기능은 없습니다.
- 영상의 **음성·자막 트랙·샘플 사이 장면**은 비교하지 않습니다.
- 자르기·큰 회전·워터마크·색상 보정·앞뒤 편집 등은 놓칠 수 있으며 비슷한 구도도 후보로 잡힐 수 있습니다.
- JPG, PNG, WebP, HEIC/HEIF, AVIF 등은 설치된 디코더 범위에서 지원합니다. RAW·애니메이션·다중 페이지 이미지·지원하지 않는 영상 코덱은 유사 비교에서 제외하고 오류 내역에 표시합니다. 읽을 수 있는 바이트가 같으면 완전 중복으로는 찾을 수 있습니다.
- 링크·정션·Windows 재분석 지점은 건너뜁니다. 하드 링크는 저장 공간을 공유하므로 한 번만 계산하며 일부 클라우드 파일도 제외될 수 있습니다.
- 정리 전 보관 파일과 대상 파일의 검색 당시 해시를 다시 확인합니다. 내용 변경·누락이 있으면 중단합니다. 검색·정리 중 다른 앱에서 파일을 편집하거나 이동하지 마세요.
- 네트워크·일부 외장 드라이브나 휴지통 용량 초과 상황에서는 Windows가 영구 삭제를 물을 수 있습니다. **휴지통 이동이 불가능하다는 안내가 나오면 취소하세요.**
- 표시 용량은 논리적 파일 크기로, 파일 시스템 압축 등에 따라 실제 확보 용량과 다를 수 있습니다.

### 성능

pHash 인덱스로 후보를 줄이고 형태 기준을 통과한 후보만 색상을 비교합니다. 한 번의 검색에서 내용 해시와 확장자가 같은 파일은 분석 결과를 재사용합니다. **앱 재실행 후에도 유지되는 분석 캐시는 아직 없습니다.** 비슷한 지문이 몰리면 최악의 비교 비용은 여전히 파일 수의 제곱에 비례합니다.

파일 읽기·디코딩에는 별도 시간이 걸립니다. CPU·RAM·디스크를 사용하고 GPU는 사용하지 않습니다. 검색은 백그라운드에서 진행되며 디코더 내부 작업 중에는 중단 반영이 늦어질 수 있습니다. 목록 썸네일은 화면에 보이는 항목부터 읽고 최근 128개까지 메모리에 보관합니다.

## 배포본 빌드

위의 개발 환경을 준비한 Windows PC에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe build_release.py
```

| 생성 경로 | 내용 |
| --- | --- |
| `dist/SameImage/` | 실행 파일과 필요한 라이브러리 |
| `release/SameImage-0.1.0-windows-x64.zip` | 다른 사람에게 전달할 실행용 ZIP |
| `release/SHA256SUMS.txt` | ZIP 무결성 확인용 SHA-256 |
| `release/package-self-test.json` | 실제 EXE 자체 점검 결과 |

PyInstaller로 콘솔 없는 EXE를 만들고, EXE 자체 점검을 통과하면 ZIP을 생성합니다. 자체 점검은 임시 파일로 HEIF 읽기, 이미지·영상 비교, GUI 미리보기를 확인합니다. 외부 구성 요소의 라이선스 고지는 배포본의 `THIRD-PARTY/`에 포함됩니다. 빌드만으로 GitHub Releases에 자동 업로드되지는 않습니다.

## 테스트

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

검색 정확성, 인덱스와 순차 비교의 결과 일치, 여러 파일 보관, 이전 선택 변경, 부분 정리 결과 유지, 창 크기·배율별 버튼 배치 등을 검증합니다. **테스트에서 휴지통 함수는 대체하므로 실제 휴지통을 조작하지 않습니다.**
