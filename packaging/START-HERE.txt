SameImage 0.1.0 · Windows x64

1. ZIP 파일을 폴더에 모두 압축 해제하세요.
2. SameImage.exe를 더블 클릭하세요. Python 설치는 필요 없습니다.
3. _internal 폴더는 실행 파일과 같은 위치에 두세요.

폴더 선택 → 검색 → 나란히 비교 → 없앨 파일 체크 → 선택 확정
→ 메인 화면의 파란색 '선택 파일 정리 → 휴지통' 버튼

각 그룹에서 여러 파일을 보관할 수 있습니다. 최소 하나는 남겨야 합니다.
유사 후보는 내용이 다를 수 있으므로 직접 확인하세요.
영상은 샘플 장면을 비교하며 음성·자막 트랙은 비교하지 않습니다.
휴지통을 비워야 실제 저장 공간이 확보됩니다.

이 배포본에는 코드 서명이 없습니다.
배포 페이지: https://github.com/Jangwanko/SameImageSearch/releases
자세한 사용 방법과 제한은 README.md를 참고하세요.
